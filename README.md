# dit_me_vat_ly: Phòng thí nghiệm vật lý ảo: Thí nghiệm định luật Ohm

## Scripts

- `npm run dev`: local dev server
- `npm run build`: typecheck + production build
- `npm run test`: smoke tests (Vitest)
- `npm run preview`: preview the production build

## Stack

React 18 + TypeScript + Vite + plain CSS. See `UI.md` for the general design reference.
