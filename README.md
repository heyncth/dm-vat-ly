# dit_me_vat_ly — Phòng thí nghiệm vật lý ảo: Thí nghiệm định luật Ohm

Phase 6–8: recording (THÊM VÀO BẢNG → rows), R = U/I per trial,
stats (R̄, SS, Se, ΔRmax), quality assessment (Đạt/Khá/Không đạt).
Visual polish (Phase 9) is the last remaining work.

## Scripts

- `npm run dev` — local dev server
- `npm run build` — typecheck + production build
- `npm run test` — smoke tests (Vitest)
- `npm run preview` — preview the production build

## Stack

React 18 + TypeScript + Vite + plain CSS. No UI framework, no DnD library,
no physics engine. See `UI.md` for the general design reference.
